# ブラウザ操作の共通入口

ブラウザ操作を含む共有スキルはこの入口を使う。個別スキルには対象URL・操作・取得する情報・保存先・完了条件を記述し、実行環境ごとのツール選択とE2E用スキルの選択はここに委ねる。

## 選択

1. 実行中のエージェントがClaude Codeなら `claude`、Codexなら `codex` を使う。両方の設定が存在することや、ユーザーが文中で呼んだ製品名から推測しない。
2. 通常の閲覧・フォーム入力・画面取得は `browser`、通常取得で不足した情報を追加確認する調査は `research`、非SPAのE2Eテスト作成は `e2e`、SPAのE2Eテスト作成は `spa-e2e` を指定する。`research` はClaude Code・Codexの両方でPlaywright MCPを使う。
3. 次を実行し、返った `provider` と、存在する場合は `skill` に従う。対応表の原本は `tools/browser/routes.json`。各スキルに対応表を複写しない。

```bash
python3 ~/src/github.com/cyokodog/claude-config/tools/browser/resolve.py --client codex --purpose browser
```

実行環境と目的に合わせて引数を指定する。このプログラムは選択結果だけを返し、ブラウザやスキルは起動しない。実際の操作は選択結果を受け取ったAIが行う。

## 選択後の実行

- `claude-in-chrome`：現在の環境に提供されているClaude in Chromeのツールで対象タブを特定し、操作する。
- `playwright-mcp`：現在の環境に提供されているPlaywright MCPのツールで対象ページを特定し、操作する。起動環境は `tools/playwright-mcp/README.md` を参照。
- `skill` が返った場合：そのスキルを利用可能な一覧から特定して実行する。Claude Codeでは対応するスキル起動機能を使う。Codexでは `tools/skill-sync/codex-compatibility.md` に従って実際の定義を読む。渡す入力は呼び出し元のファイル名・テスト内容・URLなど。呼び先がこの入口を参照しても、同じワークフローを再度起動せず、選択済みのproviderで操作を進める。
- ツール名・引数は実際に提供されている定義を確認する。Claudeのツール呼び出しを文字列置換してPlaywrightへ渡さない。操作の目的に沿って対応する機能を使う。

明示的にPlaywrightで記録するSPA用スキルなど、手順上の要件があるものは対応表で目的別に指定する。ユーザーがこの作業のツールを指定済みならその指定を優先し、対応表の既定値へ勝手に切り替えない。利用可能であることは、実際の接続・操作で確認する。

## 接続と停止条件

### 調査での利用と出力量

`research` は、検索・ページ本文・HTML・画像などの通常取得を先に使い、目的の情報が不足した場合だけ呼ぶ。不足の原因をJavaScriptだと断定する必要はない。何が取れていて何が不足しているかを整理し、追加確認するページと項目を決める。通常取得で必要な情報がそろえばブラウザは起動しない。

ブラウザを使う場合も、説明文・採寸・該当コメントなど必要な範囲を抽出する。ページ全体のスナップショットや同じ内容の再取得を繰り返さず、既に取得した内容は作業メモを再利用する。スクリーンショットは写真や見た目の確認に必要な場合に使う。必要な根拠がそろえば操作を終える。情報量は必要性で決め、トークン節約のために未確認の情報を確認済みと扱わない。

- 選択したツールが未提供・接続不可なら、その工程で止まり、再接続が必要なことを報告する。別のブラウザ方式への切り替えや推測による操作完了は行わない。
- Playwrightの専用プロファイルと通常のChromeのログイン状態は別物。ログインが必要なら、接続先とログイン状態を確認し、不足があればユーザーにログインを依頼する。別プロファイルにログイン情報を自動移植しない。
- ページ閲覧・要素探索は選択したproviderで行う。対象やデータの保存先などが曖昧なら操作前に必要な情報を確認する。
- 呼び出し元・呼び先の承認条件、公開・送信・購入などの実行範囲は維持する。共通入口への呼び出しを追加の権限とみなさない。メルカリの出品確定を押さないなど、個別の停止条件もそのまま守る。
- 終了時は呼び出し元へ結果を戻す。フローを自動で次の工程へ進めない。

この入口は、Codexから除外中のスキルを自動で利用可能にするものではない。Claude専用に確定したスキルも維持する。既存の未対応スキルは、固有の操作・ログイン・保存手順を確認してから、この入口を参照する形へ個別に移行する。
