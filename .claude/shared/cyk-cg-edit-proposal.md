# CodeGrid 修正案の作り方（共通）

原稿への修正案・文章案を出すときの手順。執筆者から繰り返し指摘されたものをまとめている。
言い回しは `cyk-cg-writing-style.md`、段落の組み立ては `cyk-cg-writing-structure.md` を参照。

## 示す範囲

- 変わる文を含む**段落全体**を示し、変わる箇所がわかるようにする（★などの印、または変更点の箇条書き）
- 文や段落を削除する場合は、削除することを明記する。「そのまま」「（以下同じ）」と書いて省略しない
- 複数の段落にまたがる変更や、段落の入れ替え・見出しの追加は、前後の段落を含めて全体を見せる
- 見出し付きの節を新しく書く場合は、その節全体を見せる

## 出す前に確かめること

1. **前後との重なり**：直した文が、前後の文と同じ言葉・同じ接続詞・同じ文末を使っていないか。部分だけ直したときほど起きやすい
2. **事実**：原稿・前回の記事・資料・コードで確かめたことだけを書く。記憶や推測で書かない。確かめられない場合は執筆者に聞く
3. **執筆者の言葉の写し**：相談中に執筆者が使った言葉を、そのまま案に入れていないか。意図をくみ取ったうえで、自分の言葉で書き直す
4. **論理**：理由と結論が本当につながっているか。条件付きでしか成り立たないことを、いつも成り立つように書いていないか
5. **スタイル**：`cyk-cg-writing-style.md` の避ける表現、`cyk-cg-writing-structure.md` の組み立てに反していないか
