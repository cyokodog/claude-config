# cyk-agent-launcher

`~/.claude/agents/cyk-*.md` を毎回その場で読み取って一覧化する。静的なリストは持たない。エージェントを追加・削除・改名しても、このスキル自体は変更不要。

## 手順

### 1. 一覧コマンドを実行する

以下をそのまま実行する（判断・探索は不要）。

```bash
for f in ~/.claude/agents/cyk-*.md; do
  name=$(grep -m1 "^name:" "$f" | sed 's/^name: *//')
  desc=$(grep -m1 "^description:" "$f" | sed 's/^description: *//')
  echo "$name — $desc"
done
```

### 2. 結果をそのまま番号付きリストで提示する

出力された `name — description` の行を、出た順に番号を振って表示する。要約や並べ替えはしない。

### 3. ユーザーに選ばせる

番号または name で選んでもらう。`$ARGUMENTS` に引数（URL・ファイルパスなど）が渡されていれば、それをどのエージェントに渡すつもりかも一緒に確認する。

- ユーザーの依頼文から目的が明らかな場合（例：「インタビュー記事を見たい」）は、該当しそうなものを候補の先頭に示してよい。ただし断定せず、選択は必ずユーザーに委ねる。

### 4. 選ばれたエージェントを起動する

`Agent` ツールで `subagent_type` に選ばれたエージェント名を指定し、`$ARGUMENTS` があればそれをプロンプトに含めて起動する。

## 注意

- `cyk-` 以外のエージェント（`Explore` や `general-purpose` など）は一覧に含めない
- エージェント定義の中身（レビュー観点など）には立ち入らず、起動の窓口に徹する
