# Codexで共有スキルから別のスキルを使うとき

Claude Code由来の `Skill` ツールによる起動は、Codexでは次の手順として扱う。

- 利用可能なスキル一覧から名前が一致するものを特定し、その実際の `SKILL.md` を読んで同じ作業の中で手順を実行する。Claudeの `Skill` ツールやClaude CLIを起動しない。
- 呼び出し元が指定した引数・対象・範囲を引き継ぐ。`$ARGUMENTS` は渡された入力を表すものとして解釈し、シェル変数の存在を仮定しない。不足する必須情報は確認する。
- 呼び先が別のスキルを使う場合も同じ規則を適用する。呼び出しの連鎖で元のスキルに戻るなど、循環が生じたら停止して報告する。
- 呼び先の承認条件・停止条件と、呼び出し元に戻ったあとの停止条件を維持する。スキルを使うこと自体を、コミット・公開・送信などの承認として扱わない。
- スキルまたは必要な外部ツールが利用できなければ、理由を報告してその工程で止まる。除外中のスキルを原本のパスから読み出して無理に実行したり、検証済みとして飛ばしたりしない。
- ツールの引数は実際に提供されている定義を確認する。原本中のツール名や引数を、そのままCodexにも存在すると仮定しない。

ブラウザ操作のツールとE2Eワークフローの選択は `.claude/shared/cyk-browser-operations.md` の共通入口を使う。入口が返したスキルに上記の読込・実行規則を適用する。除外中のスキルを直接実行する代わりに、対応済みの呼び先を共通入口で選ぶ。
